# PAIMOS AEON release codenames (AEON-430). SPDX-License-Identifier: AGPL-3.0-only
#
# Every release sequence gets an alliterative "Adjective Noun" name from these
# lists: pure science fiction (astronomy, physics, spacecraft, AI, cosmic
# phenomena), positive or neutral, easy to say, no brands, people or proper
# nouns. The letter steps through the cycle below with the sequence, and within
# a letter the shortest names come first; see codename.go.
#
# The cycle holds only letters with at least 45 adjectives and 45 nouns and
# 2,000 allowed combinations, so no letter runs out early: letters × the
# smallest letter capacity is at least 40,000 names before the first repeat.
# J, K, N, O, Q, U, V, W, X, Y and Z do not have that many good words.
#
# THIS FILE IS APPEND-ONLY. A name that was handed out must never change, so
# never reorder, edit or delete a line. To change the lists, append a new block
# at the end:
#
#   version N from S        the lines below take effect from release sequence S;
#                           S must be above every sequence already reserved
#   L adj  Word Word ...    append adjectives for letter L (words start with L)
#   L noun Word Word ...    append nouns for letter L
#   retire Word             never pick Word again from sequence S on
#   deny Adjective Noun     never pick that combination from sequence S on
#
# The cycle is part of version 1 and never changes. The deny lines hold
# combinations that are redundant ("Orbital Orbit", "Cosmic Cosmology"),
# awkward or unlucky ("Massive Meteor"). A test scans every combination for
# rude or negative readings and repeated stems and fails until a new one is
# denied here or its word is not added.
