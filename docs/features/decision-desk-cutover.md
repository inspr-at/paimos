# Decision Desk on Agents

The Desk panel on Agents replaces the former Needs you queue. It groups held and ready decisions from the canonical server projection and opens their original source records in Decision Desk. The header Desk count uses that same projection; Sessions counts continue to filter the session list. Sign-ins, connection chores and ticket triage keep their own surfaces.

Questions, held action requests, approvals, pending doctrine changes and managed session tier requests retain their native identities, permissions and decision workflows. Existing key trim requests remain available. Opening the panel or a memo does not decide, backfill or notify anything. Decided history remains accessible, including exact approval links beyond the first list page.

A memo round keeps its membership while it is open. New arrivals belong to the next round. Failed or partial reads show retry and coverage feedback; a failed canonical read leaves the count unknown. Native history pagination keeps the canonical open order, and actions recheck the source identity before recording a result. Phone memos use a full-height sheet with pinned actions, while desktop controls stay above the content.

This cutover adds an approval detail read and projection metadata without changing stored records or adding a migration. Step-up and the separate phone redesign remain independent delivery items.
